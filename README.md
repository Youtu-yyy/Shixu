本地优先的中文待办 App，Android 8.0 以上。无需账号，App 自身不申请联网权限，关闭系统云备份。

- 一句话输入，支持明天、后天、周六、下周一、年月日、中文时刻、时段、提前提醒、每天/每周/每月和 `#分类`。
- 支持常见英文日期时段（如 Friday evening、next Monday at 3:30 pm）及中英文重复、提前提醒、优先级、备注表达；建议学习/工作/生活分类。新建弹窗编辑标题会重新识别，已手动修改的字段优先。
- 中午默认 11:35—13:30，晚上 18:30—24:00；各时段可在设置中修改。
- 明确时间范围会保留两个端点，例如“下周二早上九点到十一点收快递”显示09:00—11:00，提醒基于09:00。也可手动编辑自定义时间段。
- “11月7号前交稿”识别为截止事项，默认在前一天晚上提醒（使用晚上时段的起点），并在提醒弹窗显示实际时刻；可关闭或更改提醒方式。
- 截止事项提前一个时段提醒，例如“周日晚上前”在18:30截止、下午13:30提醒，“周日中午前”在11:35截止、上午09:00提醒。时段起点随设置变化，明确提前量或“不提醒”优先；截止时间与实际提醒时间分开展示。
- 日期、时刻中的空格也能识别，例如“11 月 7 日前提交文件”和“09 : 00 到 11 : 00”；支持普通、全角及不换行空格，保留正文单词和备注。
- 时间表达兼容常见繁简写法及混写，例如“二十分鐘後提醒我交作業”“半小時後”；正文与备注保留原有文字，不整段转换繁简。
- 支持“10/22晚上18:30”这样的群消息日期；明确月日优先于后文的“明天”，明确时刻优先于模糊时段，地点和汇报内容留在正文供检查。
- 支持“11.7”“11-7”“十一月七日”“2026年11月7日”“下个月7号”“三天后”“两周后”“月底”等常见日期表达；省略年份的月日取下次到来的日期，单独“7号”取下次有效的7日，带“本月/下个月”的日期使用指定月份。
- 标题必填，日期、开始时刻或时段、备注、优先级、分类可选。
- 分类使用选择列表，支持创建自定义分类并保存在本机；首页分类筛选同步显示这些选项。
- 有时间的普通事项默认开启提醒、提前30分钟；支持“二十分钟后提醒我出门”等相对时间，明确指定多久后提醒就在该时间提醒。保存前仍可修改提醒或关闭；通知支持完成、10分钟后再提醒。
- 默认按事件开始时间排序，同时间再按优先级；优先级排序的同级事项按开始时间。当前排序显示在按钮上；时间排序时色块深浅表示优先级。也可选择手动排序长按拖动或分类排序。事项左滑显示完成/恢复操作，点击后再确认。
- 底部首页/日历切换；月历显示每天的日程数量和标题摘要，默认列出整月日程，可选日期、切换月份或回到今天。重复事项按规则展开预览，已完成事项也会显示，未定日期事项留在首页。
- 日历可切换“显示已完成”，日期标记数量、标题摘要及下方日程列表同步过滤，选择保存在本机。
- SQLite 本地持久化，已完成列表；重复事项完成后保留历史并生成下次待办。
- 重启、系统时间或时区变化时重新安排提醒。未授予准时提醒权限时采用可能延后的系统提醒。
- 中文语音输入优先使用系统离线识别；联网语音识别默认关闭，没有离线服务或中文模型时，可手动在设置中开启系统语音服务回退。App 不保存录音，系统服务可能将音频发送给服务提供方。

## 构建

重点回归测试见 [对话改进测试集](tests/regression/README.md)：56 条固定文本案例与47条验收记录。运行 `./test-regression.ps1` 可执行全部本机规则检查，结果写入 `build/regression/`；也可选择设备分组验证，真机项目单独记录。

在 PowerShell 7 中执行 `./build.ps1`，使用本机 JDK 21/Android Studio JBR 和 `F:\Android\Sdk` 中的 API 36、Build Tools 36.0.0，运行核心测试，再用 Gradle 合并离线 OCR 模型、库资源、原生库和初始化配置，打包并签署调试 APK。首次构建需要联网下载工具与依赖，缓存位于项目 `build/gradle-home`，运行时图片文字识别不需要联网。产物为 `build/Shixu-debug.apk`。只运行纯 Java 解析测试可用 `./build.ps1 -TestOnly`。

在 PowerShell 7 中运行 `./build.ps1`。模拟器已启动时，运行 `./test-device.ps1` 执行 Android 端的数据库、录入弹窗和通知送达测试；测试只创建并清理特定的“自动测试”记录。

Android Studio 可直接打开本目录（Gradle 8.13 / AGP 8.11.1，首次同步需要下载工具）。脚本和 Android Studio 沿用 `build/debug.jks` 签名；请单独妥善备份该文件，不提交到公开仓库。此 APK 使用开发签名，供个人测试。

OCR 使用 Google ML Kit `com.google.mlkit:text-recognition-chinese:16.0.1` 的 bundled 模型，开发资料和条款见 [ML Kit 官方说明](https://developers.google.com/ml-kit/vision/text-recognition/v2/android) 与 [条款及隐私](https://developers.google.com/ml-kit/terms)。模型随安装包提供，图片在本机处理。

发布手机版运行 `./build-release.ps1`，输出 `releases/拾序-版本号.apk`，保留 ARM 32/64 位支持，启用 R8、资源精简与原生库压缩。更小的 64 位手机版使用 `./build-release.ps1 -TargetAbis arm64-v8a -Output releases/拾序-版本号-64位.apk`。模拟器继续使用 `build.ps1` 的通用调试版；验证精简版本可先构建 `-TargetAbis x86_64`，再将结果通过 `test-device.ps1 -AppApk 绝对路径` 安装测试。发布签名沿用原有密钥，覆盖安装无需卸载。

原生库在安装时解压，APK 文件大小不等于系统设置显示的安装后占用。精简时不删减中文识别模型。

## 行为与限制

- 自然语言识别是本机规则解析，不是联网大模型；保存前请检查识别结果。
- 模糊时间按范围起点安排通知，不是结束时间。全天和未定日期事项需选定时间后才能开启提醒。
- 普通通知能否弹出横幅取决于手机的通知设置；勿扰、厂商省电、强行停止 App 会影响提醒。
- 时段范围的修改同时更新已保存的对应时段事项。
- 每月重复保留最初日期，例如 1月31日 → 2月28日 → 3月31日。
- 当前没有云同步、账号或导出备份，卸载/清除数据会删除记录。

后台专项测试：模拟器启动后运行 ./test-background.ps1，验证进程退出、锁屏及深度休眠下的实际通知，不打开应用界面触发补发；自动恢复模拟器电池/休眠状态并清理测试记录。

桌面小组件：从拾序设置添加，或长按桌面空白处在小组件列表选择拾序 · 桌面待办。底部提供今明事项与全部事项切换。支持调整大小、连续滚动、点击标题编辑、新增、刷新，以及右侧勾选确认完成/恢复；完成后保留划线记录并取消本次提醒。组件已添加到模拟器桌面后，可运行 ./test-device.ps1 -WidgetOnly 验证交互；测试事项使用自动测试桌面前缀，可通过widget cleanup测试模式清理。

0.6.1：完成/恢复确认在桌面小组件内部显示。支持“明天的这个时候提醒我”等表达，按指定日期与输入时相同时刻设置提醒；无具体事项标题时提供“定时提醒”。可运行 ./test-device.ps1 -SameTimeOnly 验证相关录入与保存。
