# 拾序第一版设计确认

面向个人安卓手机的待办与日程工具。主要解决记事本录入繁琐的问题。数据只保存在本机，不需要账号。

## 主要流程

1. 首页为全部待办清单，可切换今天与已完成；支持搜索、分类筛选。
2. 底部始终保留快速输入：键盘或语音输入一句话。
3. 实时预览时间识别结果。点加号后进入编辑弹窗，确认标题、日期、开始时间或时段、分类、优先级、重复和备注。
4. 点下一步时弹出独立提醒弹窗：可选择不提醒、开始时提醒、预设提前量或自定义分钟。
5. 保存后回到列表，事项在本机 SQLite 中保存。

## 时间设计

0.4.0 新增可选的明确时间段。用户输入“九点到十一点”时，开始和结束作为一个整体提取，不把“到十一点”留在标题中。识别出的结束时间存储在本机并在列表、日历和通知中展示，手动时间选择也支持编辑两个端点及“次日结束”。普通单点时间和模糊时段仍保留原方式。

截止日期和全天安排区分：例如“11月7号前交老板的采访初稿”保存为截止日期11月7日，不赋予虚假的00:00开始时间展示，而是显示“11月7日前”。默认提醒为11月6日晚上18:30，沿用设置中的晚上起点。提醒方案以“前一天晚上”的日历规则保存，不只存为固定分钟差；用户可以在提醒弹窗查看具体时间、更换提前量或关闭提醒。识别到“不提醒”或用户明确提供提前量时优先尊重该表达。

精确时刻默认只设置开始时间，也可选择明确的起止时间段。模糊时段的结束用于范围展示，与用户明确指定的结束时间分别处理。

| 时段 | 初始范围 |
| --- | --- |
| 凌晨 | 00:00—06:00 |
| 早上 | 06:00—09:00 |
| 上午 | 09:00—11:35 |
| 中午 | 11:35—13:30 |
| 下午 | 13:30—18:30 |
| 晚上 | 18:30—24:00 |

中午、晚上按用户指定的界限设置；其他为可修改的初始值。范围可在设置里调整，保存后更新同名时段事项。

提醒基于范围起点：明天中午事项提前10分钟，就是明天11:25。只有日期或未定日期的事项可保存为普通待办，开启提醒前需补充时间。

## 排列与重复

0.4.0 新建/编辑事项的分类改成选择列表，并提供“新建分类”。预置工作、生活、学习供开始使用，用户可创建自己的名称；分类选项独立保存于本机，首页筛选同步显示。自动建议仍可预选分类，但不会覆盖用户手动选定的分类。

0.2.0 增加底部“首页 / 日历”导航。日历打开时展示当前月份，网格中有日程数量与首条标题，下方默认列出当月全部日程。点选日期后显示当天日程，“查看整月”恢复月清单，箭头切换月份，“回到今天”定位今天。切换页面时保留输入框尚未保存的文字。

日历包含已完成的日程，未定日期的待办保留在首页。重复事项会按日、周、月展开未来预览，展示不写入数据库、不改变当前待办日期。未来重复预览只允许编辑原重复事项，完成操作仍从首页的当前一次处理，避免误跳过尚未完成的任务。

0.2.1 在日历页提供“显示已完成”开关，初始开启以保持原行为。关闭后，日期格标记数量和标题摘要、整月和当天列表同步排除已完成事项。开关保存在本机，重开应用时保留。隐藏不删除记录，首页的“已完成”列表仍可查看。

默认手动排序：长按卡片，拖到另一条上方。可切换按日期、分类或优先级分组，切换不会改变保存的手动顺序。

重复可选不重复、每天、每周、每月。每次完成后保留本次完成历史并推进到下一次。每月按原始日数对齐，短月份取月末。

## 语音与通知

0.3.0 扩展本机规则识别。中文例子“每周五晚上交作业，优先级高，提前半小时提醒”可提取日期、晚上时段、每周重复、学习分类、高优先级与30分钟提前量。英文例子“Friday evening, hand out homework”可提取最近的周五、晚上时段与学习分类。备注需以“备注：”或“notes:”明确标注，内容保持原文，不据此再推断其他字段。分类为可修改的关键词建议，不作事实保证。

新建弹窗的标题支持延迟500毫秒识别，下一步前也会刷新一次。输入过程中不会删除原文；保存时将已识别的日期、时段等拆到相应字段。手动选过的日期、时段、分类、优先级、重复和备注不会被自动建议覆盖。编辑既有事项时仍以手动字段为准，避免意外重新解释原有标题。

语音优先本机离线中文识别，离线服务或中文模型不可用时可调用系统语音服务，允许其联网识别。可关闭联网回退。转出的文字先回填输入框，允许编辑，确认后再保存，不保存音频。

通知提供完成、10分钟后提醒。App 会请求通知权限；准时提醒权限可以在设置里开启。横幅能否显示受系统通知渠道、勿扰模式和手机厂商策略影响。
